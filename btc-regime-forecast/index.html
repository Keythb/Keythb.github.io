Two models, one page. Current State tells you what regime today's data is in — nothing about tomorrow. Forecast gives the probability of each regime at 1–20 sessions ahead; it is a probability path, not a prediction. Click any i for what a number means and how it is computed.

Current StateWhere the data is today. Descriptive — these numbers say nothing about what happens next.

Rolling-return regime

Current state
Observed label. BTC's simple return over the trailing days, bucketed: above = Bull, below = Bear, between = Sideways. Fully mechanical — no fitting, no hidden state. This label is the input to the Forecast section below.

HMM decoded state

Current state
Hidden Markov Model. A 3-state Gaussian HMM is fit on the last days of daily log returns (Baum-Welch EM). Each state has its own mean and volatility; states are named Bear / Sideways / Bull by ascending fitted mean. The Viterbi path gives the most likely state today; the bar shows the filtered probability of each state. Unlike the rolling label, this reacts to the distribution of returns (drift and vol), so it can read Bear while the 20-day return is still positive — typically a choppy, high-vol market with negative drift.

Half-Kelly (HMM mixture)

Current state
Sizing read, not a rule. Continuous Kelly f* = μ/σ² using the posterior-weighted mean and variance across the HMM states today; shown at half-Kelly, floored at 0, capped at 2×. Risk-free assumed 0. A 1.0× means "fully invested"; 0 means the mixture drift is not positive. Cross-check against the Forecast edge below — they are independent reads.

Current state
Do the two nowcasts agree? They measure different things. The rolling label is price level vs 20 days ago; the HMM is the return distribution over the last ~600 days. Disagreement is information: Bull label + Bear HMM usually means price is up but the path there was volatile with weak drift. Bear label + Bull HMM means a sharp drop inside an otherwise healthy return distribution.
ForecastProbability of each regime 1–20 sessions ahead, given today's rolling-return label. A re-estimated model's probability path — not a price target, not a prediction.

Most likely in 20 sessions

Forecast
Markov chain, 20 steps out. Count every day-to-day regime transition across the full history ( closes) to build a 3×3 transition matrix P. Today's state is a one-hot vector; multiply by P twenty times (Chapman-Kolmogorov) to get the probability of each regime in 20 sessions. The model has no memory beyond today's label.

Regime edge vs baseline

Forecast
A tilt, not a return. Expected daily drift over the next 20 sessions conditioned on today's state, minus the drift under the long-run regime mix, annualized. Positive = today's state historically leads to better-than-average drift. Hand-off to the Kelly sizer as a directional cross-check; it is deliberately not an absolute μ.

Long-run mix

Forecast
Where the forecast converges. The stationary distribution of the transition matrix — the share of time spent in each regime if the chain ran forever. Every forecast decays toward this; the half-life of that decay is in Model Detail. It is the "no information" baseline the edge above is measured against.

Forward regime probability path
Forecast
How to read it. At "now" the bar is 100% today's state. Moving right, mass leaks into the other regimes according to the transition matrix, and the stack converges on the dashed long-run mix at the right edge. The gold numbers at the top are P(Bull) at each marked horizon. Wide = uncertain; the chart does not show a price.

Probability by horizon
Forecast
Median and 90% band. The transition matrix is estimated from finite counts, so it is uncertain. We draw 2,000 matrices from a Dirichlet posterior over each row, run each forward, and report the median with the 5th–95th percentile range. The band is estimation uncertainty only — it does not cover regime shifts or the model being wrong.

Transition matrix
Forecast
The engine. Row = today's regime, column = tomorrow's. Read "from Bull, 90% stay Bull tomorrow". Estimated on the full history and re-estimated every run. High diagonal = sticky regimes. The HMM has its own matrix in Model Detail; they are not the same object.

What each hidden state looks like. Mean and volatility of daily log returns the HMM assigned to each state (annualized ×365 / ×√365), how many of the last days were decoded into it, and the half-Kelly that state's μ/σ² implies on its own. Model detail
Hidden-state persistence. Fitted by EM, not counted from labels. Row = state today, column = tomorrow. Compare the diagonal with the Forecast matrix: the HMM typically finds stickier states because it is fit to explain the return distribution, not a ±5% threshold.

Walk-forward backtest
Model detail
Does the Markov label have any edge? Over the last days: each day re-estimate the transition matrix on a trailing -day window only, go long next day if P(Bull tomorrow | today's label) > 50%, else flat. No look-ahead, no costs. Compared to buy-and-hold over the same days. A short, in-sample-adjacent test — treat it as a sanity check, not validation.

StrategyBuy & hold

Markov diagnostics
Model detail
Expected dwell = average sessions a regime lasts once entered (1 / (1 − P(stay))). Mixing half-life = sessions for the forecast to close half the gap to the long-run mix; from the second eigenvalue of P. Mean next-day return = average daily return on days that started in each regime. Regime-implied return = those means, weighted by the forecast path and compounded.

Glossary

Regime
A persistent market state. Here: Bull / Sideways / Bear, defined two different ways on this page (rolling-return threshold, and HMM hidden state).
Markov chain
A model where tomorrow's state depends only on today's state, via a fixed table of transition probabilities. Used for the Forecast section.
Hidden Markov Model (HMM)
A Markov chain whose states are never observed directly; only returns are. The model infers which state best explains each day's return. Used for the Current State section only — this page does not forecast with it.
Nowcast vs forecast
A nowcast classifies today. A forecast assigns probabilities to future states. Current State is a nowcast; Forecast is a forecast.
Stationary / long-run mix
The regime shares a Markov chain settles into over a long run. Every forecast converges to it.
Kelly / half-Kelly
The bet size that maximizes long-run log growth, f* = μ/σ². Half-Kelly halves it for robustness to estimation error. Shown as a multiple of capital; a read, not an instruction.
Dirichlet posterior band
The range of forecasts consistent with the finite number of observed transitions. Narrow band = the matrix is well pinned down; it says nothing about whether the model is right.
