Direction × volatility grid. The trend label (Bull / Sideways / Bear) and the volatility state (Calm / Normal / Turbulent) come from two independent models and combine into one named cell — e.g. Bull trend in Turbulent vol = "Volatile Rally". Neither model speaks for the other: the volatility model never calls direction, and the trend label says nothing about the size of daily swings. When no volatility state reaches probability, the vol axis reads "shifting" until the data settles.

Trend (direction)

Current state
Observed label — the direction axis. BTC's simple return over the trailing days, bucketed: above = Bull, below = Bear, between = Sideways. Fully mechanical — no fitting, no hidden state. Direction accumulates over weeks, so it is measured on a 20-day window where drift is actually identifiable. This label is also the input to the Forecast section below.

Volatility regime

Current state
Hidden Markov Model — the volatility axis. A 3-state Gaussian HMM is fit on the last days of daily log returns (Baum-Welch EM). At daily frequency such a model separates states by volatility, not drift — daily swings dwarf daily trend — so the states are named by what they measure: Calm / Normal / Turbulent, in ascending fitted vol. The bar shows the filtered probability of each state today; a state is declared only above , otherwise the read is "shifting". This model makes no directional call: a +7% day and a −7% day look identical to it, and both belong to the Turbulent state.

Half-Kelly (combined)

Current state
Sizing read, not a rule. Continuous Kelly f* = μ/σ² at half weight, floored at 0, capped at 2×; risk-free assumed 0. Each model contributes the quantity it actually measures: the drift μ comes from the direction model (expected daily drift over the next 20 sessions given today's trend label), and the variance σ² comes from the volatility model (probability-weighted across today's vol states). Turbulence therefore cuts the size even when the trend is up — which is the correct lesson of high vol, without mislabeling it "bearish".

ForecastProbability of each regime 1–20 sessions ahead, given today's rolling-return label. A re-estimated model's probability path — not a price target, not a prediction.

Most likely in 20 sessions

Forecast
Markov chain, 20 steps out. Count every day-to-day regime transition across the full history ( closes) to build a 3×3 transition matrix P. Today's state is a one-hot vector; multiply by P twenty times (Chapman-Kolmogorov) to get the probability of each regime in 20 sessions. The model has no memory beyond today's label.

Regime edge vs baseline

Forecast
A tilt, not a return. Expected daily drift over the next 20 sessions conditioned on today's state, minus the drift under the long-run regime mix, annualized. Positive = today's state historically leads to better-than-average drift. Hand-off to the Kelly sizer as a directional cross-check; it is deliberately not an absolute μ.

Long-run mix

Forecast
Where the forecast converges. The stationary distribution of the transition matrix — the share of time spent in each regime if the chain ran forever. Every forecast decays toward this; the half-life of that decay is in Model Detail. It is the "no information" baseline the edge above is measured against.

Probability by horizon
Forecast
Median and 90% band. The transition matrix is estimated from finite counts, so it is uncertain. We draw 2,000 matrices from a Dirichlet posterior over each row, run each forward, and report the median with the 5th–95th percentile range. The band is estimation uncertainty only — it does not cover regime shifts or the model being wrong.

Walk-forward backtest
Model detail
Does the Markov label have any edge? Over the last days: each day re-estimate the transition matrix on a trailing -day window only, go long next day if P(Bull tomorrow | today's label) > 50%, else flat. No look-ahead, no costs. Compared to buy-and-hold over the same days. A short, in-sample-adjacent test — treat it as a sanity check, not validation.

Markov diagnostics
Model detail
Expected dwell = average sessions a regime lasts once entered (1 / (1 − P(stay))). Mixing half-life = sessions for the forecast to close half the gap to the long-run mix; from the second eigenvalue of P. Mean next-day return = average daily return on days that started in each regime. Regime-implied return = those means, weighted by the forecast path and compounded.

Glossary

Regime
A persistent market state. This page reads two independent axes: direction (Bull / Sideways / Bear, from a rolling-return threshold) and volatility (Calm / Normal / Turbulent, from an HMM), combined into one named cell.
Markov chain
A model where tomorrow's state depends only on today's state, via a fixed table of transition probabilities. Used for the Forecast section.
Hidden Markov Model (HMM)
A Markov chain whose states are never observed directly; only returns are. On daily returns its states separate by volatility, not drift, so here it is used strictly as a volatility classifier — it never makes a directional call and this page does not forecast with it.
Volatility regime
How large daily swings currently are, regardless of their direction: Calm / Normal / Turbulent. A violent rally and a crash can sit in the same (Turbulent) vol regime.
Nowcast vs forecast
A nowcast classifies today. A forecast assigns probabilities to future states. The Regime Read is a nowcast; Forecast is a forecast.
Stationary / long-run mix
The regime shares a Markov chain settles into over a long run. Every forecast converges to it.
Kelly / half-Kelly
The bet size that maximizes long-run log growth, f* = μ/σ². Here μ comes from the direction model and σ² from the volatility model. Half-Kelly halves it for robustness to estimation error. Shown as a multiple of capital; a read, not an instruction.
Dirichlet posterior band
The range of forecasts consistent with the finite number of observed transitions. Narrow band = the matrix is well pinned down; it says nothing about whether the model is right.
